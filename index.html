NusaDB — a relational database engine written from scratch

Lightweight, high-performance, single-node. Handles both transactional and analytical queries with MVCC, a clustered B+tree storage engine, write-ahead logging, and a cost-based SQL engine.

Capabilities

What NusaDB has today

Transactional and analytical queries on a single node, engineered for correctness.

MVCC Transactions

Serializable Snapshot Isolation plus all four standard isolation levels, savepoints, and rollback.

Storage Engine

Clustered B-link/B+tree with 8 KB pages, a clock-eviction buffer pool, and no-wait row locks.

Write-Ahead Logging

Crash recovery with CRC32 per record and lz4 compression. On restart the engine replays the durable tail of the log.

Cost-Based SQL Engine

Parser, analyzer, and planner with histogram/MCV statistics plus predicate and projection pushdown.

Rich SQL Features

  • Window functions & recursive CTEs
  • Subqueries & set operations
  • MERGE, views, sequences
  • NUMERIC (exact base-10), JSON, arrays, UUID

Secure Wire Protocol

Binary protocol over TCP with TLS (rustls) and SCRAM-SHA-256, simple & extended queries, and COPY.

Quickstart

Run it in minutes

Build from source with Cargo, or use the prebuilt Docker image. Server flags reference and TLS setup live in docs/deployment.md.

Build & test 
cargo build --workspace    # or: cargo ck (alias: cargo check)
cargo test  --workspace    # or: cargo test-all
Run server & connect 
# Start the durable server (creates --data-dir if absent)
cargo run -p nusadb-server -- --listen 127.0.0.1:5678 --data-dir ./data

# Connect with the interactive shell
cargo run -p nusadb-cli -- --host 127.0.0.1:5678
Docker

Deploy with Docker

Prebuilt server images on Docker Hub (nusadb/nusadb, linux/amd64). Use latest to track releases, or pin a version tag such as 0.1.0.

Start the server 
docker run -d --name nusadb \
  -p 5678:5678 \
  -v nusadb-data:/var/lib/nusadb \
  nusadb/nusadb:latest

# Connect with the shell shipped in the same image
docker exec -it nusadb nusa-cli
With auth & init scripts 
docker run -d --name nusadb \
  -p 5678:5678 \
  -v nusadb-data:/var/lib/nusadb \
  -v ./init:/docker-entrypoint-initdb.d:ro \
  -e NUSADB_USER=nusa-root \
  -e NUSADB_PASSWORD=change-me \
  -e RUST_LOG=info \
  nusadb/nusadb:latest
Volume

The image keeps its durable state in /var/lib/nusadb — mount a volume there or the database dies with the container.

Authentication

Setting both NUSADB_USER and NUSADB_PASSWORD enables SCRAM-SHA-256. With neither set, it runs trust-on-startup — fine for local work only.

Init scripts

SQL files mounted into /docker-entrypoint-initdb.d run once, on first startup against an empty data directory.

Server flags

Flags go after the image name, e.g. ... --metrics-listen 0.0.0.0:9100. See docs/deployment.md for the full reference.
