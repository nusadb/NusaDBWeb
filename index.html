NusaDB is a relational database for a single machine, written in Rust.

Version 0.1.0-beta.16. Serializable transactions, a cost-based SQL planner and a write-ahead log in one server binary, with its own wire protocol and drivers for eight languages. Open source under Apache-2.0.

shell
docker run -d --name nusadb \
  -p 5678:5678 \
  -v nusadb-data:/var/lib/nusadb \
  -e NUSADB_USER=app \
  -e NUSADB_PASSWORD=change-me \
  nusadb/nusadb

docker exec -it nusadb nusadb-cli --user app

Capabilities

Not in this release

  • Transactions

    MVCC snapshots, so readers never block writers. All four isolation levels up to serializable snapshot isolation, savepoints and two-phase commit.

    Transactions

  • Storage

    Rows live in the leaves of a clustered B+tree. Table and index pages are cached, evicted and spilled under --max-resident-bytes, so data can outgrow memory.

    Memory and capacity

  • Durability

    Every log record has a CRC32 and is lz4-compressed. A commit returns once its record is on disk, and a background worker checkpoints the log.

    Checkpoints

  • Query planning

    A cost-based planner uses histograms and most-common-value statistics to order joins and pick indexes. Sorts, joins and aggregates spill to disk under --work-mem.

    EXPLAIN

  • SQL

    Window functions, recursive CTEs, MERGE, ON CONFLICT, triggers, routines, partitioned tables, and exclusion and deferrable constraints.

    Statement index

  • Types

    Numeric, text, date and time, UUID, JSON, arrays, ranges, network, bit string, geometric, XML, enum and composite types, and VECTOR(n) with an HNSW index.

    Data types

  • Full-text search

    Text search with the simple, english and indonesian configurations.

    Full-text search

  • Access control

    SCRAM-SHA-256 over optional TLS or mutual TLS. Roles, GRANT and REVOKE, and row-level security policies.

    Access control

  • Encryption at rest

    Opt-in with --encryption-key-file: the log, checkpoint images, page segments, spill files and backups are encrypted with AES-256-GCM-SIV.

    Encryption

  • Backup and recovery

    Scheduled hard-link backups, a log archive with point-in-time restore, and a read-only standby that follows the archive.

    Backup

  • Clients

    Its own wire protocol on port 5678. Drivers for Rust, Java, Node, Python, Go, Ruby, PHP and .NET, the nusadb-cli shell, and COPY for bulk transfer.

    Drivers

  • Operations

    Many databases per server and many schemas per database. Metrics in Prometheus format and a systemd unit for Linux hosts.

    Metrics

Example

A session in nusadb-cli against an empty database: create a table, load five rows, then group and rank them with a window function.

Output from a 0.1.0-beta.16 build.

The worked example
nusadb-cli
CREATE TABLE orders (
  id      bigint GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
  region  text NOT NULL,
  total   numeric(10,2) NOT NULL,
  placed  date NOT NULL
);
INSERT INTO orders (region, total, placed) VALUES
  ('east', 120.00, '2026-10-01'), ('east', 75.50, '2026-10-03'),
  ('west', 210.25, '2026-10-02'), ('west', 19.99, '2026-10-05'),
  ('north', 64.00, '2026-10-04');
SELECT region,
       count(*)   AS orders,
       sum(total) AS revenue,
       rank() OVER (ORDER BY sum(total) DESC) AS rank
FROM orders
GROUP BY region
ORDER BY rank;

Recent changes

Full commit history

0.1.0-beta.16

Constraints, unique keys and partitioned tables.

  • DROP SCHEMA ... CASCADE drops the schema's tables, views and sequences and removes foreign keys that reference them. RESTRICT lists what the schema still holds (2BP01). db799f1
  • Partitions created with PARTITION OF take the parent's defaults, identity and generated columns and type checks. UPDATE ... SET col = DEFAULT works. e8e18e3
  • Foreign keys accept ON DELETE SET NULL (columns) to clear only some referencing columns. 86fe5cc
  • A PRIMARY KEY or UNIQUE key on a partitioned table no longer has to include the partition key. CHAR(n) keys are stored without trailing blanks, and REINDEX rebuilds older indexes. 0889127
  • CREATE UNIQUE INDEX takes NULLS [NOT] DISTINCT, and ON CONFLICT (cols) WHERE selects a partial unique index. aae4997
  • A NULL in NEW or OLD inside a trigger keeps its column's type. d0c606e
  • DEFERRABLE keys, foreign keys and exclusion constraints, and SET CONSTRAINTS. e31329a
  • EXCLUDE constraints over ranges are enforced and fail with 23P01. f953a5d
  • COMMENT ON covers constraints, indexes, triggers, routines, views, schemas, sequences and types, and comments are stored. 68e69e1

0.1.0-beta.15

Encryption at rest, two-phase commit and transactional DDL.

  • Schema changes made inside a transaction are invisible to other sessions until it commits. 4bdc1c6
  • Opt-in encryption at rest: --encryption-key-file, --encrypt-from and --rotate-encryption-key. ff8ce2b
  • now() and the other current-time functions return the transaction's start time. Functions are classed immutable, stable or volatile. bb95c21
  • uuidv7(), clock_timestamp(), uuid_extract_timestamp() and uuid_extract_version(). 83bdb55
  • Two-phase commit with PREPARE TRANSACTION, and protocol 1.3 notices. 0437b3e
  • A simple query may hold several statements, and COPY runs inside the open transaction block. f2996e6
  • Binary COPY, and NOT NULL checked on every write path. d52e534
  • DROP COLUMN removes the column's indexes and constraints, and dropping a sequence is transactional. cc7f280
  • Cursors and prepared statements on every extended-protocol path, and MOVE. d37aba7 8120b28
  • Bitwise operators on bigint, interval scaling and sums, and date and timestamp promotion. 6fdd1de
